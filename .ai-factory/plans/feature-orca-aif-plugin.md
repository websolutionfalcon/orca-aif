## Requirements Reconciliation
Authority: явные правила (`.ai-factory/rules/base.md`) > `.ai-factory/ARCHITECTURE.md` > `.ai-factory/DESCRIPTION.md` > `.ai-factory/ROADMAP.md` (только объём). Ограничения Orca host API (`orca skills get orca-plugin-authoring`, типы `.orca/types`) — жёсткие внешние факты.

| Решение / поддерживаемая комбинация | Источник | Проверка |
|---|---|---|
| Клик по status bar «открывает панель»: в host API нет метода показа панели плагина. Решение: item запускает `aif.summary` (строковый результат Orca показывает как есть) + отдельная декларативная команда `aif.toggleSidebar` (`action: "sidebar.right.toggle"`) | `DESCRIPTION.md` — «Основные возможности»; `references/host-api.md` — список методов worker | тест `worker.test.ts`: `aif.summary` возвращает строку; ручная проверка клика |
| Поиск активного плана — тот же алгоритм, что у `/aif-implement` (ветка → единственный именованный → `paths.plan` → `paths.fix_plan`) | `.ai-factory/references/ai-factory-artifacts.md` — «Поиск активного плана» | тесты `plans.test.ts` на каждый шаг |
| Пути артефактов из `config.yaml` `paths.*`, fallback на значения по умолчанию | `ai-factory-artifacts.md` — «Раскладка файлов» | `config.test.ts` |
| Плагин только читает `.ai-factory/`; в терминал — только команда из каталога + очищенный аргумент, только по действию пользователя | `DESCRIPTION.md` — НФТ «Безопасность»; `ARCHITECTURE.md` — принцип 4 | `commands.test.ts` (санитизация), `commandService` тесты |
| Состояние workspace × артефакты: `no-workspace` / `remote` (hostId `ssh:`/`runtime:`) / `not-installed` (нет `.ai-factory/` и `.ai-factory.json`) / `no-plan` / `in-progress` (done<total) / `done` (done=total>0) / `error` (чтение упало) | `ARCHITECTURE.md` — принцип 2; `ROADMAP.md` — «Надёжность и совместимость» | `status.test.ts`: по одной фикстуре на состояние + реальный `.ai-factory/` этого репозитория как end-to-end фикстура |
| Отправка команды × агент: есть агент в workspace → `terminal.sendText` в его терминал; нет агента → `agent.launch` с `prompt`; аргумент обязателен и не передан (палитра) → текст `/<skill> ` без Enter + `terminal.focus`; есть только запуск → `agent.launch` без prompt не делаем, показываем ошибку «введите аргумент в панели» | `DESCRIPTION.md` — «Быстрые команды»; типы `terminal.sendText {enter?}`, `agent.launch {prompt?}` | `commandService.test.ts`: 4 комбинации |
| Префикс: `/` для Claude и slash-агентов, `$` для `codex`; настройка `commandPrefix` (`auto` / `/` / `$`) перекрывает | `ai-factory-artifacts.md` — «Команды»; `DESCRIPTION.md` — «Настройки» | `commands.test.ts` |

Meaning preservation: PASS — объём «весь плагин за один проход» сужен только пользовательским выбором (milestones 1–9, без публикации); формулировки требований DESCRIPTION/ROADMAP перенесены без ослабления, кроме явно зафиксированного API-ограничения про открытие панели.
