# Project Roadmap

> Плагин Orca ADE для AI Factory: быстрые команды `/aif-*` для агента текущего workspace и статус `.ai-factory/` в status bar и боковой панели.

## Milestones

- [ ] **Каркас плагина** — `orca plugin create` (worker-panel → HTML-панель), манифест, типы `.orca/`, структура по ARCHITECTURE.md; `dev watch`, `test` и `validate` проходят
- [ ] **Разбор артефактов AI Factory** — чистый `core`: пути из `config.yaml`, поиск активного плана как в `/aif-implement`, разбор fast/full/ultra/fix-планов и ROADMAP.md, модель `AifStatus`; тесты на фикстурах
- [ ] **Чтение workspace и живое обновление** — адаптер файловой системы, реакция на `workspace.changed` / `agent.status.changed`, опрос mtime `.ai-factory/`, кэш в `orca.storage`
- [ ] **Индикатор в status bar** — `AIF 3/8`, tone и tooltip по состоянию (нет AI Factory / нет плана / в работе / готово), клик открывает панель
- [ ] **Быстрые команды** — каталог `/aif-*`, префикс `/` или `$` по агенту, отправка в терминал агента или запуск нового агента, команды палитры и keybindings, безопасная вставка аргумента
- [ ] **Боковая панель: статус и план** — HTML-панель на `protocol.ts`: наличие артефактов, активный план с задачами и прогрессом, открытие файлов в редакторе
- [ ] **Панель: roadmap и кнопки команд** — прогресс milestones, кнопки быстрых команд с вводом аргумента, состояние агента
- [ ] **Настройки плагина** — агент по умолчанию, режим отправки, префикс, набор команд, интервал опроса, `logLevel`
- [ ] **Надёжность и совместимость** — отсутствующие или битые артефакты, локализованные заголовки, SSH-workspaces, пути Windows, `orca plugin check` без ошибок
- [ ] **Документация и публикация** — README, иконка, cover и скриншоты, `validate`/`inspect`, тег `v<version>`, топик `orca-plugin`, запись в каталог
