# Использование

Плагин следит за **workspace в фокусе**: при переключении workspace или ветки (включая `git checkout` без изменения файлов плана) статус пересчитывается. Кнопки панели показывают префикс, с которым команда реально уйдёт запущенному агенту.

## Status bar

| Индикатор | Состояние | Когда |
|-----------|-----------|-------|
| скрыт | `no-workspace`, `not-installed` | Нет workspace или нет `.ai-factory/` / `.ai-factory.json` |
| `AIF` | `no-plan` | AI Factory настроен, активного плана нет |
| `▷ AIF 3/8` | `in-progress` | Есть план, не все задачи отмечены (план без задач — `0/0`) |
| `✓ AIF ✓ 8/8` | `done` | Все задачи плана отмечены `[x]` |
| `AIF ?` | `ambiguous` | Подходит несколько именованных планов |
| `AIF !` | `error` | Ошибка чтения файлов workspace |
| `☁ AIF` | `remote` | Workspace на SSH/runtime-хосте |

Подсказка показывает план и прогресс roadmap (`Roadmap: 8/10 milestones · Next: …`).
**Клик** показывает вкладку **AI Factory** в правой боковой панели (открывает панель, если она закрыта, и переключает на вкладку плагина). Текстовую сводку показывает команда палитры «AI Factory: Show status».

## Боковая панель

| Блок | Что показывает |
|------|----------------|
| Заголовок | Workspace и ветка, кнопка «Обновить» |
| План | Название (клик — открыть файл), тип `fast`/`full`/`ultra`/`fix`, прогресс, оставшиеся задачи по фазам; выполненные свёрнуты под «Выполнено (N)»; следующая задача помечена ▶, commit-задачи — курсивом |
| Roadmap | `done/total` milestones, список с отметками, следующий milestone ▶ |
| Контекст | `config.yaml`, описание, архитектура, roadmap, правила — открываются кликом. У отсутствующих — кнопка, которая запускает в агенте workspace создающую их команду: `/aif` (config, описание), `/aif-architecture`, `/aif-roadmap`, `/aif-rules` |
| Предупреждения | Проблемы чтения: файл больше 1 MiB, путь вне workspace, неверные значения `config.yaml` |
| Библиотека скилов | Все скилы AI Factory проекта (`aif`, `aif-*`) из папок агентов (`agents[].skillsDir` в `.ai-factory.json`). Строка поиска и спойлер: без запроса список свёрнут, запрос раскрывает его и оставляет совпадения по названию и описанию (все слова запроса, без учёта регистра; Esc очищает). Клик по имени открывает `SKILL.md` |

При `ambiguous` вместо задач — список подходящих планов со ссылками.

## Какой план считается активным

Тот же порядок, что у `/aif-implement`:

1. План текущей ветки: `<plans>/<ветка с / → ->.md` или ultra `<plans>/<stem>/index.md` (с `workflow.plan_id_format: sequential` — наибольший `NNNN_<stem>`; ultra важнее при равенстве).
2. Единственный именованный план в `<plans>/` (кроме `PLAN.md` и `FIX_PLAN.md`); если их несколько — `ambiguous`.
3. Fast-план `paths.plan` (по умолчанию `.ai-factory/PLAN.md`).
4. Fix-план `paths.fix_plan`.

Ultra-бандл распознаётся только по маркеру `<!-- aif:plan-mode:ultra -->` (ровно один в `index.md`); папка с несколькими маркерами пропускается с предупреждением, как в `/aif-implement`. Архив (`paths.archive`) не учитывается. Прогресс — по строкам `- [ ] Task N:` / `- [x] Task N:`; если нумерованных задач нет, считаются все чекбоксы.

## Куда уходит команда

| Ситуация | Что делает плагин | Результат |
|----------|-------------------|-----------|
| В workspace есть агент, аргумент есть или не нужен | Вводит команду в его терминал и нажимает Enter | `Отправлено` |
| Агента нет (или `sendMode: always-launch`) | Запускает `defaultAgent` с командой как prompt | `Запущен агент с` |
| Агент есть, обязательный аргумент не указан, команда из палитры | Вводит `/aif-plan ` **без Enter** и фокусирует терминал — допишите описание сами | `Вставлено в терминал агента` |
| Обязательный аргумент не указан в остальных случаях | Ничего не отправляет, показывает ошибку | `Ошибка` |
| Единственный агент ждёт разрешения | Ничего не отправляет и не запускает | `Ошибка` |

Агент выбирается так: сначала ожидающий ввода, затем завершивший, затем работающий. В агента, который **ждёт разрешения**, команда не отправляется никогда — Enter подтвердил бы запрос; если других агентов нет, плагин отказывает и просит сначала ответить на запрос. Аргумент очищается: одна строка, без управляющих символов, до 500 символов.
