# Доступ и безопасность

Плагин работает в профиле **`trusted-worker`**: его worker — отдельный процесс Node.js на хосте Orca с правами вашей учётной записи. Поэтому Orca спрашивает согласие перед установкой и при любом расширении доступа.

## Запрашиваемые разрешения

| Разрешение | Для чего плагину | Методы Orca |
|------------|------------------|-------------|
| `workspace:read` | Узнать workspace в фокусе, его папку и ветку; события смены workspace | `workspace.readContext`, `workspace.list`, событие `workspace.changed` |
| `workspace:write` | Открыть файл артефакта в редакторе; сфокусировать терминал агента после вставки команды | `editor.open`, `terminal.focus` |
| `agent:read` | Найти агента workspace и показать его состояние | `agents.list`, событие `agent.status.changed` |
| `agent:launch` | Запустить агента с командой, если в workspace его нет | `agent.launch` |
| `terminal:send` | Ввести команду `/aif-*` в терминал агента | `terminal.sendText` |
| `storage:own` | Запомнить последний статус между перезапусками worker | `storage.get/set` |
| `settings:own` | Читать настройки плагина | `settings.get` |
| `notifications:show` | Уведомить о завершении плана | `notifications.show` |

`terminal:read`, `secrets:own`, `workspace:create`, автоматизации и история сессий **не запрашиваются**.

## Что плагин делает и чего не делает

| Делает | Не делает |
|--------|-----------|
| Читает `.ai-factory/` и `.ai-factory.json` workspace в фокусе | Не пишет, не переименовывает и не удаляет файлы проекта |
| Отправляет в терминал только команды из фиксированного каталога `/aif-*` | Не отправляет произвольный текст и не читает вывод терминала |
| Отправляет команду только по вашему действию: кнопка или палитра | Ничего не отправляет само по событиям или таймерам и никогда — агенту, ждущему разрешения |
| Читает файлы только внутри папки workspace | Не следует по symlink и путям `..` за её пределы |
| Работает без сети | Не делает сетевых запросов |

## Защитные меры в коде

- **Аргумент команды:** одна строка, управляющие и ANSI-последовательности удаляются, до 500 символов (`src/core/commands.ts`).
- **Пути:** пути из `config.yaml` с `..` или абсолютные отклоняются. Реальный путь (`realpath`) проверяется на нахождение внутри workspace. Файлы больше 1 MiB не читаются (`src/worker/workspaceFs.ts`).
- **Открытие файлов:** панель открывает только пути, которые перечислены в текущем статусе — артефакты, план, roadmap, кандидаты (`openablePaths` в `src/worker.ts`).
- **Панель:** sandboxed-фрейм без сети и файловой системы. Текст выводится только через текстовые узлы, без `innerHTML`.
- **Содержимое файлов** — данные, а не инструкции: плагин ничего не исполняет из `.ai-factory/`.
- **Логи** не содержат текстов файлов и аргументов.

## Удалённые workspace

Для workspace на SSH/runtime-хостах статус `remote`: worker работает локально и не читает удалённые файлы. Команды и запуск агентов по-прежнему маршрутизирует Orca.
